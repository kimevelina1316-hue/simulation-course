### Марковская модель погоды

**Задание:**  
Смоделировать погоду по дням:

- 1 — ясно  
- 2 — облачно  
- 3 — пасмурно  

Единица времени — **1 день**.  
Задать интенсивности переходов между состояниями.

**Требования:**
1. Выполнить моделирование в «реальном» времени с визуализацией.
2. Провести статистическую обработку результатов.
3. Сравнить эмпирическое распределение с теоретическим стационарным.
4. Сбор статистики и всей необходимой информации в .txt или .csv формат (.csv формат предпочтительней)

**Ключевые функции программы:**

**generateExponential(λ)** - Генерация экспоненциально распределённого времени пребывания

**getNextState(i, Q)** - Выбор следующего состояния по вероятностям перехода

**calculateStationaryDistribution(Q)** - Расчёт теоретического стационарного распределения итерационным методом

**runSimulation()** - Основной цикл

**exportToCSV()** - Экспорт результатов для дальнейшего анализа
