### Базовый датчик случайных чисел

**Задание:**

Базовый датчик самописный реализован через  **МуЛьТиПлИкАтИвНыЙ КоНгРэУрЕнТнЫй** метод.

<img width="1482" height="256" alt="image" src="https://github.com/user-attachments/assets/708ba215-1594-4be2-b0b8-22ff258fa89a" />

  в коде для него создала метод GeneratCustomSamples(который реализует генератор)

Для встроенного генератора  использовала С#

<img width="666" height="191" alt="Screenshot 2026-03-24 210829" src="https://github.com/user-attachments/assets/2a598c51-b10d-4666-9d31-ff0937cb6af7" />

  в коде для него создала метод GebrateBuiltInSamples (который реализует выборку)

Размер выборки — **100 000 значений**


Теоритические значения - получаем через одну из критериев Базового датчика, а именно **Равномерно распределённая случайная величина**. 
Которая преобретает теоритические значения дисперсии и среднего для равномерной случайной величины в диапазоне от 0 до 1.

Сравниваем наши средние и дисперсные результаты  выборок с теоритическими значениями, самописным датчиком + программный датчик.
