### Клеточные автоматы. Лесные пожары (GUI)

**Задание:**  
Реализовано моделирование возникновения и распространения лесных пожаров с использованием двумерного клеточного автомата.

Дополнительные правила:
1)Ветер(восточный)
  работатет так, что распространяется огонь вправо с вероятностью 70%, слева с вероятностью 30%
2)Молнии
  12-13 молний на итерацию, с вероятностью попадания 0,005 (т.е 5 на 1000)
3)Река
  Зона которая не поджигается.
