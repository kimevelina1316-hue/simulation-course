<img width="1181" height="585" alt="Screenshot 2026-04-01 014518" src="https://github.com/user-attachments/assets/59b90dce-63ac-410b-83b2-fd33b05a7890" />
  
   Рис1.Интерфейс программы. 

1.Был использован тот же датчик из Части 1. Только теперь у нас не два варианта событий. 
Использование 6 вариантов ответов для Шара с предсказаниями.

2. Использовался прогрев генератора.

  Алгоритм генерации вариантов: 
  
1. мой генератор → α ∈ [0, 1)
2. Отрезок [0,1] делится на 6 интервалов (по вероятностям)
3. Находим, в какой интервал попало α
4. Возвращаем номер ответа → показываем текст
